## 先說我為什麼開始寫

我不是命理師，只是一個對紫微斗數好奇了很久的人。學的過程中最困擾的是：資料很多、說法很雜、每本書的用語又不太一樣。所以我決定把自己讀懂的部分，用最白話的方式整理在這裡，也順便逼自己把觀念釐清。

這個站的每一篇都是「筆記」，不是「教學」——會有錯、會修改，文章上方的「更新」日期就是它最後一次被我改動的時間。

## 命盤是一張十二格的表

紫微斗數的核心工具是「命盤」。它把一個人出生的年、月、日、時換算成一張十二格的表，每一格叫做一個「宮」，每個宮裡會落入不同的星曜。

十二宮分別是：

| 宮位 | 大致代表 |
| --- | --- |
| 命宮 | 本人的性格與整體格局 |
| 兄弟宮 | 手足、同輩關係 |
| 夫妻宮 | 感情、伴侶 |
| 子女宮 | 子女、創作、晚輩 |
| 財帛宮 | 金錢觀、賺錢方式 |
| 疾厄宮 | 身體、健康傾向 |
| 遷移宮 | 外出、人際印象 |
| 交友宮（僕役宮） | 朋友、部屬 |
| 官祿宮（事業宮） | 工作、事業 |
| 田宅宮 | 居住、家庭、不動產 |
| 福德宮 | 精神狀態、興趣、福分 |
| 父母宮 | 父母、長輩、上司 |

初學時不用一次記住全部，先抓住「命宮」和它正對面的「遷移宮」，再慢慢往外擴散就好。

## 星曜：落在哪一宮，就影響哪個面向

紫微斗數有十四顆主星（紫微、天機、太陽、武曲、天同、廉貞、天府、太陰、貪狼、巨門、天相、天梁、七殺、破軍），再加上一堆輔星、煞星、雜曜。

看盤的邏輯很簡單：

> 某顆星，落在某個宮，這個宮的主題就會帶有那顆星的性質。

例如「太陽」在「官祿宮」，常見的解讀是工作上容易站在明處、需要付出、適合對外的角色；同一顆太陽如果在「夫妻宮」，講的就變成伴侶的樣子。

星曜本身沒有好壞，重點是它跟宮位、跟其他星的組合。

## 這個筆記站會怎麼寫

預計會分成幾個系列：

1. **十二宮** — 一宮一篇，講每個宮在問什麼問題。
2. **十四主星** — 一星一篇，講性格、優缺點、常見組合。
3. **四化** — 化祿、化權、化科、化忌，這是紫微斗數最有趣也最容易搞混的部分。
4. **心得雜記** — 學習過程中的碎念。

如果你跟我一樣是剛入門的人，歡迎一起慢慢看。
